# Шрифты

Здесь должны лежать `Montserrat.ttf` и `Anton.ttf`. Оба под SIL Open Font License.

В репозитории их нет — запустите `scripts/fetch_fonts.sh`.

Кириллица в обоих есть, проверено. Если подставляете свой шрифт, убедитесь,
что кириллические глифы на месте, иначе libass отрисует пустые прямоугольники.
