# Шрифты

Нужны `Montserrat.ttf` и `Oswald.ttf`. Оба под SIL Open Font License, оба с
полной кириллицей. В репозитории не лежат — запустите `scripts/fetch_fonts.sh`.

## Почему не Anton

Изначально узкие стили («три состояния», «неон») стояли на Anton. У него
**нет кириллицы вообще** — ноль из тридцати заглавных, вместо русских букв
libass рисует пустые прямоугольники.

Ловушка в том, что замер ширины строки этого не показывает: PIL и libass
возвращают ширину и для отсутствующих глифов. Проверять надо отрисовкой —
сравнением с заведомо отсутствующим символом. Так и работает `cyrillic_ok()`
в `captions.py`, которая теперь предупреждает при генерации.

Oswald подобран как замена по метрике: «НАКЛЕЕК» при 60 px занимает 208 px
против 210 у Anton, то есть узкий вид сохраняется.

## Свой шрифт

Если подставляете свой — проверьте кириллицу отрисовкой, а не шириной.
